AI Data Analyst

An AI-powered platform that automatically analyses datasets, generates insights, builds machine learning models, and answers questions in natural language.

Product Requirements
Functional Requirements

Our application should allow a user to:

✔ Upload CSV/Excel files

✔ View dataset summary

✔ Detect missing values

✔ Detect duplicate rows

✔ Detect outliers

✔ Generate charts

✔ Automatically clean data

✔ Train ML models

✔ Compare different models

✔ Explain predictions

✔ Chat with the dataset

✔ Export a PDF report



Non-Functional Requirements
The application should:
Handle datasets up to ~100 MB smoothly.
Be easy to use without coding knowledge.
Display results quickly.
Be modular so new features can be added easily.
Use only free libraries and services.
